# Working Hours Register

A 90-minute, four-level assessment. Each level builds on the previous one, and the
platform carries your code forward automatically.

| Level | Topic | Difficulty |
| ----- | ----- | ---------- |
| 1 | Employee tracking and completed working time | easy |
| 2 | Top N employees by working time | medium |
| 3 | Promotions and historical salary | hard |
| 4 | Double-pay grant periods | hard |

Language: JavaScript (CommonJS). Every level expects a `WorkingHours` class exported
from `solution.js`.

Run `npm run verify` to check that all reference solutions pass every public and
hidden test.
